# Development History

These archives preserve the historical implementation trail. They are retained for research traceability and are not imported or executed by the active repository.

| Archive | Historical stage | Retained decision context |
|---|---|---|
| `iteration_01_initial.zip` | Initial proof-of-concept | Established the structural constraint idea and exposed weak semantic quality. |
| `iteration_02_candidate_expansion.zip` | Candidate expansion | Candidate gate remained below target: 27.44% overall recall and 45.71% aggregate-operation recall. |
| `iteration_03_operation_expansion.zip` | Operation expansion | Overall recall improved to 43.40%; aggregate-operation recall remained below the 75% gate at 68.57%. |
| `iteration_04_ranker_and_aggregation.zip` | Ranker/aggregation revision | 32.03% overall recall, 71.43% aggregate recall; learned ranker underperformed the heuristic. |
| `iteration_05_final_engineering_build.zip` | Final historical build | Final candidate gate reached 48.68% overall and 28/35 aggregate cases (80%), enabling the full development comparison. |

The active repository root represents the subsequently cleaned and validated implementation package. The archive names are neutralised to prevent historical build labels from being mistaken for active source files.
